# ADI (Aprendizagem e Decisão Inteligentes) (Português)

Projeto de grupo realizado no âmbito da UC de Aprendizagem e Decisão Inteligentes. O projeto consiste na conceção, implementação e avaliação de modelos de Machine Learning aplicados a dois conjuntos de dados distintos.

# ADI (Intelligent Learning and Decision) (English)

Group project carried out within the scope of the Intelligent Learning and Decision course. The project consists of the design, implementation, and evaluation of Machine Learning models applied to two distinct datasets.

## Model visualization
This project was developed using the [KNIME](https://www.knime.com/downloads) platform, so it is necessary to install the platform and import the workflows (compressed `.knwf` files) to visualize the implemented models.
